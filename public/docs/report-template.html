How the template works

CARE replaces placeholders in braces, for example {{projectTitle}}. Keep every required placeholder in the document so exports can patch all sections.

  • Use a Word .docx file only.
  • Keep placeholder names exact, including case.
  • The key unintendedConsequneces must remain spelled exactly like this.

Branding and colours

Generated table headers and AI/glossary labels use your template accent colour:

  1. CARE first tries the Heading 1 colour from your template.
  2. If Heading 1 has no colour, CARE uses the template theme accent.

Upload and verify

  1. Open Organisation and go to Report template (Word export).
  2. Upload your edited .docx.
  3. If placeholders are missing, CARE shows the missing keys so you can fix and re-upload.
  4. Run a Word export from an evaluation to verify the output.

Placeholder reference (all required keys)

Include every placeholder below in your template (exact spelling inside double braces, for example {{title}}).

  • {{doctitle}} — Large report title text on the cover.
  • {{title}} — Project title in the report body.
  • {{author}} — Project owner name and email.
  • {{footertitle}} — Project title in the footer/header area.
  • {{date}} — Full publication date.
  • {{footerdate}} — Publication year for footer usage.
  • {{objectives}} — Project objectives text.
  • {{aiAssistedNotice}} — AI-assisted disclosure/notice section.
  • {{intendedConsequences}} — Bullet list of intended consequences.
  • {{positiveUnintendedConsequences}} — Bullet list of positive unintended consequences.
  • {{dataUsed}} — Data used summary text.
  • {{stakeholders}} — Bullet list of stakeholders.
  • {{donutChart}} — Embedded risk distribution donut chart image.
  • {{averageLikelihood}} — Average likelihood metric.
  • {{averageImpact}} — Average impact metric.
  • {{averageRisk}} — Average overall risk score.
  • {{topRisks}} — Table of top risks and risk levels.
  • {{aiProvenance}} — AI provenance appendix (when included).
  • {{glossaryAppendix}} — Glossary appendix section (when included).
  • {{unintendedConsequneces}} — Main unintended consequences table (legacy spelling required).
