How the template works

CARE replaces placeholders in braces, for example {{title}}. Include every required placeholder so exports can patch all core sections. Optional placeholders may be omitted or added when you want extra content (charts, footers, summaries).

  • Use a Word .docx file only.
  • Keep placeholder names exact, including case.
  • The key unintendedConsequneces must remain spelled exactly like this.

Branding and colours

Generated table headers and AI/glossary labels use your template accent colour:

  1. CARE first tries the Heading 1 colour from your template.
  2. If Heading 1 has no colour, CARE uses the template theme accent.

Upload and verify

  1. Open Organisation and go to Report template (Word export).
  2. Upload your edited .docx.
  3. If placeholders are missing, CARE shows the missing keys so you can fix and re-upload.
  4. Run a Word export from an evaluation to verify the output.

Placeholder reference

Ordered to follow a CARE evaluation. Use exact spelling inside double braces. Tags show whether each key is required for upload validation.

  • Report metadata
  • {{doctitle}}Required — Large report title on the cover.
  • {{title}}Required — Project title in the report body.
  • {{author}}Required — Project owner name and email.
  • {{date}}Required — Full publication date.
  • {{footertitle}}Optional — Project title in the footer or header area.
  • {{footerdate}}Optional — Publication year for footer usage.
  • Project details
  • {{objectives}}Required — Project objectives text.
  • {{dataUsed}}Required — Data used summary text.
  • {{aiAssistedNotice}}Required — AI-assisted disclosure and notice section.
  • Intended consequences
  • {{intendedConsequences}}Required — Bullet list of intended consequences.
  • Unintended consequences
  • {{positiveUnintendedConsequences}}Required — Bullet list of positive unintended consequences.
  • {{unintendedConsequneces}}Required — Main unintended consequences table (legacy spelling required).
  • Stakeholders
  • {{stakeholders}}Required — Bullet list of stakeholders.
  • Risk evaluation and reporting
  • {{riskBandSplitChart}}Optional — Embedded risk-band split chart (High / Medium / Low / Unclassified).
  • {{riskMatrixChart}}Optional — Count matrix for likelihood vs impact.
  • {{riskCountsSummary}}Optional — Summary counts for High, Medium, Low and Unclassified risks.
  • {{riskEntryMatrix}}Required — Static risk matrix listing risks inside each cell.
  • {{topRisks}}Optional — Table of top risks and risk levels.
  • Appendices
  • {{aiProvenance}}Required — AI provenance appendix (when included in export).
  • {{glossaryAppendix}}Required — Glossary appendix section (when included in export).
