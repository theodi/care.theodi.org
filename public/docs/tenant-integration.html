Tenant integrations API

Developer documentation · CARE read-only organisation API · v1

Overview

This API exposes machine-readable JSON for evaluations that are shared with your organisation. Put your Tenant ID in the URL path and an integration API key in the Authorization: Bearer … header. Organisation admins create and revoke keys on the Organisation page (active subscription required).

JSON endpoints require Accept: application/json (otherwise 406). The Word report endpoint (GET …/projects/{id}/report) requires Accept: application/vnd.openxmlformats-officedocument.wordprocessingml.document instead.

Finding IDs

  • Tenant ID — On the Organisation page under Integrations API, or as tenantId in GET /organisation with Accept: application/json.
  • Project ID — On Evaluations, under each title (copy control), or id from the API list response.
  • Your project ID (integrationExternalId) — Optional. Organisation admins and Project managers set Your project ID on organisation-shared evaluations (modal from the organisation evaluations table). When set, it appears on list, detail, summary, and work-item payloads for easier matching in Zapier, Make, n8n, or custom integrations.
